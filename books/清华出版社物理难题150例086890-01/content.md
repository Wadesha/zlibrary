## 001 悬链线的几何特征

问题 拿出一根蛇骨链，两手捻住两端，使其处在同一高度，你会看到一个神奇的曲线。

这个曲线是什么曲线？

有没有解析表达式？

你可以移动双手改变蛇骨链两端的水平距离。

## 在做这个实验的过程中

你会发现，水平距离D缩短

## 链条的高度H就加长

反之亦然（参照题图）。

那么，这两个几何特征长度到底满足什么样的关系？

解析 首先利用微元分析法来推导悬链线方程。

设悬链线的长度是l，线密度是ρ。

由对称性，设悬链线的最低点（通常为中点）为原点，最低点悬挂重物，质量为m。

## 弧长坐标为s的绳子微元受到三个力

两端的张力，大小分别为T(s)和T(s+ds)

## 重力G=ρgds

如图1所示。

绳子微元受力平衡，将其在水平和竖直方向进行分解，得

## d(T(s)cosθ(s)) = 0 (1)

## d(T(s)sinθ(s)) = ρgds (2)

其中θ(s)为弧长坐标s处悬链线切线与水平方向的夹角，且有

dx = cosθ(s)ds, dy = sinθ(s)ds (3)

悬链线最低点重物受力平衡，有

## T(0)sinθ(0) = mg (4)

其中T(0)为悬链线最低端的张力，θ(0)为悬链线最低端切线与水平方向的夹角。

## 由式(1)、式(2)和式(4)解得

## T(0)cosθ(0)tanθ(s) = ρgs (5)

### x(τ) = (kl/sinhτ(0)) * (τ - τ(0)) (6)

y(τ) = (kl/sinhτ(0)) * (coshτ - coshτ(0)) (7)

## 其中比例系数k为重物质量m与悬链线质量ρl的比值

## 它与参数τ(1)

## τ(0)的关系式为

## 由式(6)和式(7)得到悬链线的半宽度D和高度H分别为

D = x(τ(1)) = (kl/sinhτ(0)) * (τ(1) - τ(0)) (9)

H = y(τ(1)) = (kl/sinhτ(0)) * (coshτ(1) - coshτ(0)) (10)

式(8)中，两个参数τ(0)和τ(1)是有约束关系的

不是独立的，所以式(9)和式(10)实际上只是一个独立参数的表达式

也就是悬链线半宽度D和高度H的参数方程。

练习 实际做实验，验证式(9)和式(10)。

注解 以上推导最关键的一步是变量替换，即tanθ = sinhτ。

### 这样做的好处是几乎所有的物理（数学）量都有初等函数的解析表达式

便于物理上的表示和求解。

## x(τ) = (l/sinhτ(1)) * τ

### y(τ) = (l/sinhτ(1)) * (coshτ - 1)

τ(0)、τ(1)等参数含义同上题。

## T(0) = ρgl / sinhτ(1)

l(down) = T(end) / ρg = d * coshτ(1) / τ(1)

由对称性，链条总长度的一半L等于两个钉子之间悬链长度的一半l加上下垂长度l(down)

d * coshτ(1) / τ(1) + d * sinhτ(1) / τ(1) = L

## 继续化简得到

## exp(τ(1)) = L / d (1)

## 再考虑一端固定

## 其余部分搭放在另一钉子上的链条

### 此时链条的总长度L等于两个钉子之间悬链长度的l加上下垂长度l(down)

d * coshτ(1) / τ(1) + d * sinhτ(1) / τ(1) = L

## 继续化简得到

(2sinhτ(1) + coshτ(1)) / τ(1) = L / d (2)

## 003 跳绳的形状

## 问题 现在让链条动起来

## 绕着两端连线的水平轴匀速转动起来

这就是我们所熟悉的跳绳。

那么跳绳的形状是什么样的？

解析 为简单起见，先不考虑重力的影响，这样不同角度（界面）的跳绳形状都一样。

## 以绳子两个固定端点的连线为x轴

## 设转动绳子中的张力（分布）为T

## 绳子微元的坐标为(x

y)，并采用弧长s和切角θ坐标

如图1所示。

## 由微分几何知识可知

dx = cosθ(s)ds, dy = sinθ(s)ds

绳子微元水平方向受力为零，张力垂直分量之差提供向心力，由此得

## d(T(s)sinθ(s)) = -ω²ρy(s)ds

## d(T(s)cosθ(s)) = 0 (1)

## 由式(1)中第二个方程很容易积分得

## T(s)cosθ(s) = T(0)

其中T(0)为绳子中点部分的张力。

代入式(1)中的第一个方程，得到

### d(T(0)tanθ(s)) = -ω²ρy(s)ds (2)

再设p = tanθ = dy/dx，式(2)化为

## T(0)dp = -ω²ρy(1 + p²)dy

## 继续化简得

### dp / (p² + 1) = - (ω²ρ / T(0)) y dy

## 积分得

### arctan(p) = - (ω²ρ / (2T(0))) (y² - h²)

其中h为绳子中点到两端水平连线的垂直距离。

长度以h为单位，并设λ = ω²h²ρ / T(0)，则有

### dy/dx = p = tan( (λ/2)(1 - y²) )

令k² = λ / (λ + 2)，则式(3)化为

### dx = dy / sqrt( (1 - y²)(1 - k²y²) )

对上式积分，并定义a为绳子两端距离的一半，则有

由椭圆函数的定义，可得式(4)的解

y = sn( (λ + 2)^(1/2) * (a - x), k )

其中sn为雅可比椭圆函数。

这就是无重力环境下两端固定转动绳子时绳子的形状方程。

注解1 按以上的模型，跳绳的形状与转速没有关系。

转速越大，最高处（中心）的张力也越大

使参数λ = ω²h²ρ / T(0)保持为常数。
