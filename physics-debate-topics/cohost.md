# 助播指南

如果你不是主讲人，而是助播/搭档/副机位，以下是你需要准备的东西。

---

## 一、硬件准备

| 物品 | 说明 |
|------|------|
| 手机支架 × 2 | 一个拍主讲人，一个拍白板/公式特写 |
| 补光灯 | 环形灯即可 |
| 白板 + 白板笔 | 写公式用，比 PPT 更自然 |

## 二、助播分工

### 助播的 4 个核心任务

**① 写公式**
- 主讲人说到公式时，助播同步写在白板上
- 字体要大，笔顺要慢

**② 拆台 / 补刀**
- 主讲人讲完一边观点，助播立刻接："但是！"
- 举出反方观点，制造冲突感

**③ 控制节奏**
- 每段控制在 30-45 秒

**④ 评论区互动**
- 重点回复：质疑公式的、提出反例的、问延伸问题的

## 三、助播话术模板

### 开场
```
助播：（指着白板上的公式）"今天这个公式，你先猜一下，是啥意思？"
```

### 制造争议
```
助播："等一下，你刚才说的不对吧？"
主讲："哪不对？"
助播："xxx 理论说，其实应该是……"
```

### 反转
```
助播："但 2022 年诺贝尔奖出来了……"
主讲："对，实验证明爱因斯坦错了"
```

### 收尾
```
助播："所以问题来了——评论区说说你的看法"
```

## 五、拍摄 SOP

### 拍摄前
- [ ] 确认本期话题
- [ ] 白板写好核心公式
- [ ] 灯光调好，白板不要反光

### 拍摄中
- [ ] 每段控制在 30-45 秒
- [ ] 主讲人说核心观点时，助播不要出声

### 拍摄后
- [ ] 检查评论区，回复前 10 条评论

## 六、参考话术

当观众说"没听懂"：
```
"没听懂正常，这个连物理学家都吵了 100 年"
```

当观众质疑公式：
```
"公式是物理学界公认的，但怎么解释它，大家看法不一样"
```

> 助播的定位：不是"助理"，是"对手"。观众想看的是两个人在争论，不是一个人在讲课。
