## 关键坑：git 失效目录清理
- WPS 云同步会把已删的旧目录不断写回磁盘；`git add -A` 会重新跟踪它们。
- 移除跟踪必须用 `git rm --cached -r`；但 `git ls-files` 默认对中文路径做八进制转义，`xargs`/文件来回传会损坏路径(出现`?`)，`git rm` 报 pathspec 不匹配。
- **正确做法**：`git ls-files -z`(原始字节) → 解码 → 在 Python 内直接 `subprocess git rm --cached -r`，避免文件/终端编码往返。
- 并在 `.gitignore` 追加失效目录条目，阻止再次被 `git add` 跟踪。
- 沙箱会拦截 `shutil.rmtree` 与磁盘删除；`git rm`(含 --cached) 需 `dangerouslyDisableSandbox`。
- `rm -f` 会触发 safe-delete 并可能残留 `.git/index.lock`，提交前需 `rm -f .git/index.lock`。
