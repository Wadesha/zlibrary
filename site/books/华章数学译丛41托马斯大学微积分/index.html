法则 5 导数的积法则

若 u 和 v 在 x 是可微的，则它们的积在 x 是可微的，且有

d(uv)/dx = u(dv/dx) + v(du/dx)

积 uv 的导数等于 u 乘 v 的导数加上 v 乘 u 的导数。

用函数记号写成

(fg)'(x) = f(x)g'(x) + f'(x)g(x)

例 6 求 y = x e^x 的导数。

解 对 u = x 和 v = e^x 应用积法则：

dy/dx = x(e^x) + (1)(e^x) = (x + 1)e^x

积法则的证明由导数定义，

d(uv)/dx = lim_{h→0} [u(x+h)v(x+h) - u(x)v(x)] / h

为了把这个分式改写成一个等价的形式

使其包含 u 和 v 的导数的差商

在分子中减去和加上 u(x+h)v(x)

= lim_{h→0} [u(x+h)v(x+h) - u(x+h)v(x) + u(x+h)v(x) - u(x)v(x)] / h

= lim_{h→0} u(x+h)[v(x+h) - v(x)]/h + v(x)[u(x+h) - u(x)]/h

因为 u 是连续的，所以 lim_{h→0} u(x+h) = u(x)。

式中两个分式分别趋近于 dv/dx 和 du/dx 的极限，简记为

uv' + vu'

(b) 对于这个特别的乘积

若 u 和 v 在 x 是可微的

则商 u/v 在 x 是可微的

d/dx [u(x)/v(x)] = [v(x)u'(x) - u(x)v'(x)] / [v(x)]^2

d/dx [f(x)/g(x)] = [g(x)f'(x) - f(x)g'(x)] / [g(x)]^2

解

dy/dx = [(x - 1)(2x) - (x^2 + 1)(1)] / (x - 1)^2 = [2x^2 - 2x - x^2 - 1] / (x - 1)^2 = (x^2 - 2x - 1) / (x - 1)^2

d/dx [u(x)/v(x)] = lim_{h→0} [u(x+h)/v(x+h) - u(x)/v(x)] / h = lim_{h→0} [u(x+h)v(x) - u(x)v(x+h)] / [h v(x+h)v(x)]

使其包含 u 和 v 的导数的差商

减去和加上 u(x)v(x)

于是得到

= lim_{h→0} [u(x+h)v(x) - u(x)v(x) + u(x)v(x) - u(x)v(x+h)] / [h v(x+h)v(x)]

= lim_{h→0} [v(x)(u(x+h) - u(x)) - u(x)(v(x+h) - v(x))] / [h v(x+h)v(x)]

对分子和分母取极限就得到商法则。
